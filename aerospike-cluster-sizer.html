Formulas — Total storage = size × objects × RF × (1 + WB overhead). RAM = index (64B/record × RF) on storage-engine device, or data + index in memory mode. Device IOPS = writes/s × RF × defrag + reads/s × (1 − cache hit) if device. Nodes = max(storage, ram, iops) with growth margin applied to storage/ram.
